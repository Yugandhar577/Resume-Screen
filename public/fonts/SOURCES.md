# Bundled fonts

NotoSans-Regular.ttf is the pre-existing SIL OFL font used for Latin, Greek, and Cyrillic text.
NotoSansDevanagari.ttf is a regular static instance (wght=400, wdth=100) of the Google Fonts
Noto Sans Devanagari variable font, instantiated with fontTools 4.66.1 on 14 October 2026.
Source: https://github.com/google/fonts/tree/main/ofl/notosansdevanagari
Copyright/license: OFL-Devanagari.txt. Instancing retains font source license/attribution.

PDF downloads use ReportLab 5 and HarfBuzz shaping. Hindi combining marks and mixed
Latin/Greek/Cyrillic text have roundtrip extraction tests. This is a bounded language
sample, not a guarantee for every Indic script or typography case.
